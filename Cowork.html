01

What is Claude Cowork?

Say

Claude Cowork is a task-completion mode inside Claude. Regular Chat mainly gives us answers. Cowork can take a goal, work through several steps, use approved files and tools, and return a finished document, spreadsheet, presentation, research summary, or organised set of files. We explain the result we need, and Cowork plans how to produce it.

ChatCowork
“Tell me how to do this.”“Complete this task for me.”
Best for questions and quick drafts.Best for multi-step work, files, research, and finished outputs.
Usually works one response at a time.Can plan, execute several steps, and continue while we step away.

The one-line version for a sceptical room: Chat is where you think; Cowork is where the work lands. If the answer to your request is a file rather than a paragraph, that's a Cowork task.

02

What do I need to set it up?

Say

First, we need a paid Claude plan. We can start Cowork from Claude on desktop, web, or mobile — though which surfaces you get depends on the plan and on company settings. For direct access to local files, the browser, or the computer, the Claude Desktop app must be installed, open and connected. Sessions themselves run in the cloud; the desktop app is the bridge to your machine.

Basic setup

  1. Open Claude and select Cowork beside the message box.
  2. Create a dedicated working folder — something like Claude Cowork — and place only the relevant copies of files inside it.
  3. Connect only the folders, apps and services the task actually requires.
  4. Add preferred tone or output rules under Settings → Cowork, then Edit next to Global instructions.
  5. Begin in Manual mode. Move to Auto only for familiar, low-risk work, and treat Skip as something you opt into deliberately, never as a default.

The three approval modes

These were renamed — if your notes or a colleague's screenshot say “Ask before acting” or “Automatically approve”, they're describing the same three settings under older labels.

Manualwas “ask before acting”
Claude asks before it acts. Recommended for sensitive or unfamiliar work, and the right place to start on day one.
Autowas “automatically approve”
Actions run without prompting you — but Claude still reviews each action for safety first and blocks unsafe ones. Auto is not the same as unguarded, which is worth saying out loud; people assume it is.
Skipwas “skip all approvals”
No checks on Claude's actions. Reserve it for cases where every file, tool, source and action is fully trusted. One backstop survives even here: deleting a file always requires your explicit permission.
Recommended first-day setup

Dedicated folder · Manual mode · no sensitive files · one small test task

If you change one thing after this talk, make it the dedicated folder. Almost every Cowork regret starts with “I pointed it at my whole drive.”

03

How do I use it?

Say

A good Cowork request describes the finished result rather than every click. I give it five things: the goal, the source material, the output, the rules, and the review point.

The five-part prompt formula

PartWhat to provide
GoalWhat must be accomplished?
SourcesWhich files, folders, websites or apps may it use?
OutputWhat should it create, and where should it save it?
RulesWhat must it include, avoid, preserve or verify?
ReviewWhen must it pause or ask for approval?
Example prompt · all five parts
Review the meeting notes in the selected folder. Create a one-page Word summary with decisions, owners, and deadlines. Do not change the original files and do not send anything. If an owner or date is unclear, mark it as "Needs confirmation." Show me the draft for review before finalizing it.

Read it back and point at each clause: goal, sources, output, then two rules — don't modify, don't send — and finally the review point. The negative rules are doing the most work. “Do not send anything” is the difference between a draft and an incident.

Normal workflow

  1. Give Cowork the task and the relevant source material.
  2. Review its proposed approach before it starts working.
  3. Let it work — while watching for unexpected files, websites or actions.
  4. Redirect it if the task begins to move outside the requested scope.
  5. Check the final output before sharing, publishing, sending or relying on it.
04

Best practices

Say

The main principle is simple: give Cowork enough access to complete the task, but no more. Start with reversible work, keep human review for important decisions, and increase autonomy only after the workflow is proven.

DoAvoid
Start with a small, clearly defined task.Beginning with a large or sensitive workflow.
Use a dedicated folder containing copies.Giving access to an entire drive or confidential folders.
State the output format and success criteria.Vague instructions such as “sort this out.”
Keep Manual for sensitive or unfamiliar work.Using Skip for messages, purchases, financial work or important files.
Watch the overall task and stop unexpected behaviour.Assuming every action or source is automatically safe.
Verify names, numbers, dates, citations and calculations.Treating the first output as final without review.
Use Chat for simple questions, Cowork for multi-step work.Spending Cowork usage on tasks that only need a quick answer.
Schedule only stable, low-risk tasks — and review every run.Scheduling tasks that send messages or make consequential changes unattended.
The risk worth naming

Prompt injection — and the two conditions it needs

Cowork may read untrusted content from websites, email or documents. Instructions hidden in that content can try to redirect an AI agent. That's prompt injection — and the useful part is that it needs both of these at once:

Condition 1Claude can read content from outside your trusted sources.
AND
Condition 2Claude can take a consequential action.

Break either one and the attack has nowhere to land. That is the whole defence, and it maps onto things you already control: narrow the folder and the connectors (breaks condition 1), or keep Manual mode on anything that sends, pays, publishes or deletes (breaks condition 2). Anthropic also runs content classifiers that scan untrusted content entering Claude's context and flag likely injections — a backstop, not a substitute for scoping the job.

Callback to Level 5: this is the same argument as least privilege via a PreToolUse hook — the difference between “please don't” and “you can't.” Cowork's approval modes are that control, exposed for people who don't write code.

05

A 60-second example

Say

Imagine I have ten meeting-note files. Instead of opening each one, I place copies in a dedicated folder and ask Cowork to identify decisions, actions, owners and deadlines. I tell it not to edit the originals, to flag missing information, and to produce one summary for my review. Cowork plans the work, reads the permitted files, prepares the summary, and shows me the result. I then verify the important details before distributing it.

This is the ideal shape of a first Cowork task — and every element is deliberate:

Input

Multiple sources

Ten files is enough to be tedious by hand — the work is worth delegating.

Process

Several steps

Read, extract, cross-reference, format. Not a single question, so Chat is the wrong tool.

Output

One clear deliverable

A named format in a known place. You can tell instantly whether it worked.

Scope

Limited access

Copies in a dedicated folder. Nothing consequential is reachable.

Safety

Fully reversible

Originals untouched, nothing sent. The worst case is a wasted draft.

Control

Human review at the end

You check the details that matter before anyone else sees them.

06

Closing line

“The easiest way to think about Claude Cowork is as a capable digital colleague: give it a clear outcome, the minimum access it needs, sensible boundaries, and a final review. Start small, supervise important work, and automate only after the process is reliable.”

Final checklist — before starting any Cowork task

  • Is the goal and final output clear?
  • Have I shared only the files and tools needed?
  • Have I protected the originals and excluded sensitive data?
  • Is the approval mode appropriate for the consequences?
  • Have I said what Cowork must not do?
  • Will a person review the result before it matters?
