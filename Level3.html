    The hygienist's checklist
    01 — manual

    Audit before you prompt

    One clean project per task. Load the one file the job needs, not the whole shared drive. Default state is a cost.

    02 — automated

    Let Tool Search prune definitions

    The platform now lazy-loads tools — default-on in Claude Code, opt-in on the API. Don't rebuild this — know it's there, and stop fearing big tool libraries. Worth switching on past 10 tools or 10K tokens of definitions; defer_loading leaves your cached prefix intact, so it composes with prompt caching.

    03 — manual

    Own the rest

    Stale files and sprawling threads aren't auto-pruned. That hygiene is still your job, every session.

Tool Search's >85% reduction is published; it is default-on in Claude Code but opt-in on the API (you declare the search tool and set defer_loading: true). Docs put tool-selection degradation above 30–50 available tools — the older 79.5%→88.1% accuracy pair was measured on Opus 4.5 and is no longer published, so it has been removed.
    Base overhead is small and now published per model: with at least one tool present you pay a tool-use system prompt of 286 tokens on Opus 5, 354 on Sonnet 5, 496 on Haiku 4.5 — definitions, not scaffolding, are the tax.
    Read the bar as cost, not capacity. This track models the 1M default window (Opus 5, Sonnet 5, Opus 4.6+, Sonnet 4.6 — no beta header, no long-context premium; Haiku 4.5 and Sonnet 4.5 stay at 200K). That is deliberately unflattering to the bar: a 55K stack is only ~5.5% of 1M, and even every connector switched on stays under 14%. That is the honest picture, and it is the point. "You're out of room" was the weakest version of this argument and the platform has now taken it away. The two that survive a big window: those tokens are re-read and re-billed on every turn — so the cost scales with conversation length, not with capacity — and selection still degrades past 30–50 tools regardless of how much room you have. Light setups (1–2 connectors) feel little of this; the tax scales with the stack.
