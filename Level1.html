How These Numbers Are Calculated

PDF tokensextracted text + (pages × per-page image cost). Anthropic's PDF docs: each page is also rendered as an image at ~1,500–3,000 tokens — that image overhead is exactly what Markdown removes.
MD tokensreal extracted text ÷ 4 (Anthropic's ~4-chars-per-token rule of thumb).
$ costtokens × input rate. Opus 4.8 $5 · Sonnet 4.6 $3 · Haiku 4.5 $1 per million (verified Jun 2026).
$ basisAPI per-token pricing. On claude.ai (subscription) the same waste shows up as context saturation and usage caps, not a dollar bill.
CaveatText-token estimate; not a byte-exact tokenizer. The order-of-magnitude gap is the point, and it's real.
